# Математические проверки

`just check-lean` проверяет закреплённый Lake-проект и аксиомы деклараций
из `lean-proofs.json`. Локальный готовый mathlib можно указать переменной
`LEAN_MATHLIB`. Версии и коммит закреплены в `checks/lean/`.

В I, §1 полный строгий функтор отражает изоморфизмы объектов. Проверка
строит оба морфизма через полноту, затем отражает два равенства для
обратных морфизмов через строгость. Она не охватывает последующий
критерий эквивалентности категорий и построение квазиобратного функтора.

Сопоставление обозначений и точные ограничения указаны в каждом
Lean-файле. Места книги связаны с проверками смысловыми метками.

`checks/sage/morita_picard.py` проверяет два конкретных примера для II,
(3.3) и (5.1). Нулевые спаривания над полем показывают, почему строгость
тензорного функтора сама по себе не заменяет инъективность спаривания.
Перестановки простых слагаемых кольца из трёх полей показывают обращение
порядка при переходе от бимодулей к функторам правых модулей. Скрипт
не доказывает общую теорему Мориты или классификацию группы Пикара.

В III (2.10) Lean проверяет биномиальный многочлен при `n=2`: его дефект
делится на квадрат `a(1-a)`, а разность с `a` — на `a(1-a)`. При нулевом
квадрате дефекта результат идемпотентен. Два угловых тождества для
`(1-e)a(1-e)` проверены в произвольном кольце, без коммутативности.
Sage проверяет исходную биномиальную конструкцию и совместимость
сравнений для `1 ≤ n ≤ 12` в `Z[a]`. Произвольная нильпотентность и
адическая полнота этими проверками не доказываются.

В III, §3, с.96 `idempotent_radicals.py` перебирает все элементы шести
колец: Fₚ[t]/(t²) и Fₚ×Fₚ[t]/(t²) при p=2,3,5. В них проверены
равенство √(eA)=eA+nil(A) и единственность идемпотента по этому радикалу.
Ненулевой элемент t с t²=0 опровергает напечатанное √(0)=0. Это проверки
указанных конечных колец. Lean отдельно доказывает, что нильпотентный
идемпотент равен нулю, и шаг единственности для двух идемпотентов в
коммутативном кольце. Общее равенство радикалов и существование
идемпотента не формализованы.

В V (1.2) и (1.7) `linear_block_identities.py` проверяет 18 051 матричное
тождество и контрпример к слову «последний» в (1.2). Блоки имеют размер 2×2
и не обязаны коммутировать. Для верхнетреугольных блоков проверены 1600
случаев над F₃; для факторизаций Уайтхеда — все пары из GL₂(F₃), а затем
все пары из GL₂(Z/4), у которых второй блок сравним с единицей по идеалу
2(Z/4). Это конечные точные проверки, без доказательства для произвольного
кольца или классификации его нормальных подгрупп.

В V (5.2) `linear_normality_signs.py` проверяет два знака в сопряжении
трансвекции матрицей `I−s₁e₃₁−s₂e₃₂`: член при `e₃₂` имеет знак минус,
а соответствующий элемент обратной матрицы — плюс. Выполнено 1000 точных
проверок над F₅ и для семейства некоммутирующих блоков из M₂(F₃). Проверка
охватывает эти матричные тождества; общее доказательство нормальности
элементарной группы в неё не входит.

Для I (8.6) `sequential_translations.py` проверяет контрпример к замкнутости
выбранных стрелок при повторяющихся частичных суммах: две петли с метками
12 и 28 имеют отсутствующую композицию с меткой 40. Условие (S) выполнено
благодаря поглощающему элементу ∞ в каждом хвосте; проверены 4160 конкретных
свидетельств. Отсутствие метки 40 для всех интервалов следует из точного
перебора малых индексов и нижней границы 64 для последующих конечных членов.
Lean проверяет два общих алгебраических равенства: дополнение квадрата
кофинальности и уравнивание параллельных трансляций без сокращения.
Категория индексов и общая теорема о копределах не формализованы.

В IX (5.9) `conductor_module.py` проверяет, что действие подкольца
`A=F₂+x²B` на `M(x²B)`, где `B=F₂[x]/(x⁸)` и `M=A/(x⁴A)`, не продолжается
до действия `B`. Перебраны все 512 матриц размера 3×3 над F₂ на базисе
`x²,x³,x⁵`: ни одна не задаёт требуемого действия `x`. Это контрпример
к промежуточному шагу исходного доказательства; он не опровергает
эпиморфность гомоморфизмов в самом предложении. Общее исправленное
доказательство через ядро и коядро продолжения скаляров не формализовано.

В XI (6.2) `cyclotomic_class_groups.py` вычисляет с `proof=True` классовые
числа колец целых двух полей: Q(ζ₃) и Q(ζ₉). В обоих случаях результат
равен единице. Для второго поля дополнительно проверены интервальная
верхняя граница Минковского меньше 9/2, степень вычетов простого 2
и норма 1−ζ₉. Проверка относится только к этим двум полям; результаты
о других групповых кольцах и полях в неё не входят.

На с.572 `abelian_two_group_symbols.py` проверяет размерность пространства
экспонент квадратичных норменных символов для группы C₂⁴. На 15 ненулевых
характерах произведения аффинных функций над F₂ образуют пространство
размерности 11; проверены все 1024 произведения. Поэтому ошибочная
факторгруппа с полным целевым произведением μ₂¹⁵ имеет размерность не меньше
4. Вывод SK₁(Z[C₂⁴])=0 обоснован в редакционном примечании опубликованной
точной последовательностью, а не этим вычислением. Общая исправленная
теорема для нечётного p не формализована.

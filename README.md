# Х. Басс. Алгебраическая К-теория

Исходники издания на Typst. Русский текст: «Мир», Москва, 1973;
перевод с английского А. В. Михалёва, под редакцией Е. С. Голода.

PDF книги и отдельный список исправлений доступны в
[релизах](https://github.com/stdcall/bass-1973/releases). В каждом релизе
есть `SHA256SUMS` для проверки файлов.

Издание сохраняет текст, обозначения и нумерацию утверждений.
Подтверждённые исправления перечислены в `corrections.json`.
Оглавление, ссылки и указатели используют страницы данного издания.

Для сборки и правки исходников см. [CONTRIBUTING.md](CONTRIBUTING.md).
Область математических проверок описана в [checks/README.md](checks/README.md).
